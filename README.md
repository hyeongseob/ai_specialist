# 분야별 출제 포인트 및 자가 점검 체크 포인트

## 1. LLM

### 모델의 원리 이해

- 주요 Layer들의 의미, 동작 원리, 구성 방법, 활용 방법에 대해 이해하고 있는가
- 데이터의 입력부터 출력까지의 Tensor 타입 값의 주요 흐름에 대해 이해하고 구성할 수 있는가
- 모델에서 어떤 내용을 학습하는지 알고, 그 학습에 필요한 작업들을 알고 있는가

### 데이터 구성 원리 이해

- 모델과 학습 또는 평가 의도에 맞게 데이터를 구성하는 방법을 이해하고 있는가

## 2. RAG

### RAG 구성 이해 및 활용

- RAG의 구성 요소 및 주요 흐름에 대해 이해하고, 그 활용 방법을 알고 있는가

### 관련 Library 활용

- llama-index, mcp 등의 RAG 관련 Library들을 적절하게 사용할 수 있는가

## 3. Data

### 모델의 원리 이해

- 모델의 구조, 구성 방법, 동작 원리 및 방법, 활용 방법에 대해 이해하고 있는가
- 데이터의 입력부터 출력까지의 Tensor 타입 값의 주요 흐름에 대해 이해하고 구성할 수 있는가
- 모델의 결과와 정답을 이용하여 학습으로 연결시킬 수 있는가

### 데이터 구성 원리 이해

- 모델과 학습 또는 평가 의도에 맞게 데이터를 구성하는 방법을 이해하고 있는가

### 관련 Library 활용

- sklearn 등 실험에서 다뤘던 주요 Library들을 사용할 수 있는가
- 학습에 필요한 Library를 목적에 맞게 사용할 수 있는가

### 평가 Metric 이해

- 평가 Metric의 원리와 방법을 이해하고 있는가

## 4. Vision

### 모델의 원리 이해

- 모델의 주요 Layer의 의미, 구성 방법, 동작 원리, 활용 방법에 대해 이해하고 있는가
- 모델의 결과와 정답을 이용하여 학습으로 연결시킬 수 있는가

### 데이터 구성 원리 이해

- 모델과 학습 또는 평가 의도에 맞게 데이터를 구성하는 방법을 이해하고 있는가

### 관련 Library 활용

- torchvision.transforms 등의 이미지 데이터를 변형하는 다양한 방법을 이해하고 있는가

### 평가 Metric 이해

- 평가 Metric의 원리와 방법을 이해하고 있는가

## 5. On-device

### Quantization

- 모델을 Layer 단위에서 양자화/역양자화 하는 과정을 이해하고 있는가

### Pruning

- 가중치의 중요도를 판단하는 기준을 이해하고, 이를 통해 불필요한 연산을 제거하는 과정을 이해하고 있는가

\* Distillation

- 지식증류의 원리를 이해하고, Teacher 모델의 예측값과 정답값을 활용해서 Student 모델 학습에 연결시킬 수 있는가
